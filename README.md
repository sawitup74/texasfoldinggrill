# texasfoldinggrill.com

Guide site for Slot Grill (https://slotgrill.com). Static HTML generated by `build.py` from `content_*.py`, served by GitHub Pages (custom domain in `CNAME`).

Build: `python3 build.py` (rewrites all .html, style.css, favicon.svg, sitemap.xml, robots.txt, 404.html, CNAME).

GoatCounter: the counter URL is the single constant `GOATCOUNTER` at the top of build.py, currently the placeholder `https://GC_CODE_texasfoldinggrill.goatcounter.com/count`. To switch on counting:

    sed -i 's/GC_CODE_texasfoldinggrill/YOURCODE/' build.py && python3 build.py && git commit -am "Set GoatCounter code" && git push

Every slotgrill.com link gets `utm_source=texasfoldinggrill&utm_medium=referral&utm_campaign=guide-site`, and clicks on them are counted as GoatCounter events (path `click-to-slotgrill/<page>`).
